# melin Astro template

A static Astro recreation of the supplied storefront capture. All captured images,
fonts, and styles are served locally. Live Shopify, analytics, advertising, account,
chat, and checkout scripts were intentionally removed so captured identifiers or
credentials are not shipped.

```sh
npm install
npm run dev
npm run build
```

This is a visual template. Commerce forms and outbound product links require a new,
authorized backend before they can process real transactions.
